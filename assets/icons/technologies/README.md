# Technology icons

The .NET mark (`dotnet.svg`) is the unmodified official logo from [dotnet/brand](https://github.com/dotnet/brand/blob/main/logo/dotnet-logo.svg); its license is retained in DOTNET-LICENSE.txt. The other SVGs are from [Devicon](https://github.com/devicons/devicon), commit `6a37858047b0e8d9c9c0e68f4a071fc410652e89` (master), original variants. MIT license retained in LICENSE.txt. Product marks remain owned by their respective owners.

All images are served locally. GitHub receives a CSS inversion so its monochrome mark remains visible on the dark background. WPF, WinForms and ASP.NET use the .NET family icon; REST, VPS, hosting, algorithms and SSE use the existing generic portfolio sprite rather than an invented product logo. Every icon is accompanied by visible text and decorative icons are hidden from assistive technology.
